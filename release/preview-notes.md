Native Windows x64 local-music preview, made with ❤️ by Prem. Adapted from the Android application Podium Air.

## Install

Download **Podium-Air-Windows-0.2.0-x64.msi** (recommended), or the setup EXE. The portable ZIP runs without installation. The Java runtime is included. These packages are unsigned; Windows may display a SmartScreen warning.

## Included

Local library, metadata/artwork, favorites/history, editable playlists and M3U interchange; queues, repeat/shuffle, real playback/seek/volume, equal-power crossfade, rate/EQ/sleep; TTML/LRC lyrics, artwork motion and Replay statistics. Native Windows file/folder dialogs, system media controls and optional tray/startup/notifications are included.

Windows CI checks 40 tests, all 15 routes and detail views, keyboard/DPI startup, six real audio formats (WAV/FLAC/Opus/MP3/AAC-M4A/AIFF), crossfade/natural end, missing-file recovery, native controls/dialog cancellation and MSI install/run/uninstall. **BUILD_EVIDENCE.txt** records the exact source commit and successful workflow. **SHA256SUMS.txt** verifies every attached file.

## Preview limits

This is a local-music preview, not full Android parity. YouTube/Google streaming, login, downloads and account sync are unavailable. Automix, online canvas/lyrics/translation, scrobbling/Discord/Listen Together, network account clients/addons and Replay sharing remain incomplete. Physical Windows 10/11 devices, media keys, mixed-monitor DPI, output hotplug, long sessions and listening quality still require user testing. FLAC/Opus/AAC preparation uses bounded 16-bit PCM; detailed limits are in BUILD_REPORT.md and FEATURE_PARITY.md.
